# papa-yeti-canyon-fishing-rescue-30s-3x2

Cinematic 3x2 timed storyboard prompts for `prompts/papa-yeti-canyon-fishing-rescue-30s-storyboard.md`. One grid per 10-second video, three in total, each holding exactly six panels: row 1 is Shot 1 (panels 1 and 2), row 2 is Shot 2 (panels 3 and 4), and row 3 is Shot 3 (panels 5 and 6), and each panel is one beat of that shot's `Action:`, timed and framed by the panel map in section 6 of `.agents/rules/cinematic-direction.md`. Each prompt carries the locks as section 2 of `.agents/rules/prompt-assembly.md` sets out, with each Yeti's face given per panel in an `Expressions:` sentence. The images are saved to `3x2-timed-storyboard-images/papa-yeti-canyon-fishing-rescue/`, named after the panel and video number.

To use a grid in Google Flow:
1. Generate each panel image with the family reference image attached, the image output set to the film's aspect ratio, and the prompt pasted whole.
2. Check each panel: six panels in order, no text in the images, and every panel through the look check in section 7 of `.agents/rules/prompt-assembly.md`. Regenerate any panel that fails.
3. Run `compose_grid.ps1` to build the grid image from the six panel images.
4. Generate the video's clip in ingredients-to-video mode with the grid image and the family reference image attached, and the video's table from the storyboard pasted as the prompt. Never set a panel as a start or an end frame.
5. Check the clip against the six panels, each at its timecode.
