# Carousels

One file per published reel, written by the `reel-carousel` skill.

Each file holds four square 1:1 image prompts that retell the reel's storyboard as a swipeable Facebook carousel, the caption with hashtags, a short alternate caption for A/B testing, and four on-image overlay lines.

Naming: the storyboard's slug with the `-30s-storyboard` or `-60s-storyboard` suffix replaced by `-carousel`, so `prompts/babu-yeti-kung-fu-dream-60s-storyboard.md` becomes `carousels/babu-yeti-kung-fu-dream-carousel.md`.
