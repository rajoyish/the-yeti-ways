# Papa Yeti Warm Dome 30s Image Prompts

Still-frame image prompts for `prompts/papa-yeti-warm-dome-30s-storyboard.md`. One frame per shot, nine in total, numbered in film order. Each prompt carries the same aspect ratio line, style lock, environment sentence, character text, head lock, and `Animals:` sentence as the matching video shot, with the `Action:` rewritten as a single held image. The `[EXPRESSION]` slot in each character text is filled per frame from the table in section 5 of `.agents/rules/character-consistency.md`, matching the feeling the Yeti holds in that frame.
